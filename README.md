# CTI 课程知识图谱平台

学院课程知识图谱与 CTI 能力矩阵的单文件网页原型。

## 使用

使用浏览器打开 `index.html`，无需安装依赖或后端。

包含课程基本信息编辑、19 项 CTI 能力等级录入、能力矩阵、雷达图、课程对比、图谱编辑、知识重叠检查和数据完整性提示。

## 数据

- 默认数据来自用户提供的课程备份，包含 3 门课程与 4 项建设进度。
- 修改保存在当前浏览器 localStorage 中，不能自动在用户或设备之间同步。
- 通过“CTI 能力矩阵”导出或导入完整 JSON 备份。
- 保存操作不会修改本仓库的 HTML，也不会向 GitHub 提交内容。
- 待核对的旧知识图谱不计入有效知识统计。
- 本原型没有用户登录或权限控制。

## 维护

页面的 HTML、CSS 和 JavaScript 均在 `index.html` 内，修改后保存并提交即可维护网页版本。

## 部署

可作为静态网站部署。首页 `index.html` 放在仓库根目录，无需编译。
部署前确认内置课程信息可以向网站访问者展示。
